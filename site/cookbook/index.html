THE COOKBOOK

dashboard recipes,
as plain files.

Every surface below is a folder of markdown — the dashboard note plus the sheets and sample rows it binds to. Install is copy-paste: put the files in your vault and the board renders with numbers on first open. Then make it yours.

By hand — open a recipe, download its files, drop them into your vault. Keep the Dashboards/ nesting or don't; folders never decide what belongs to a database.

By agent — recipes are agent food. Point your agent at index.json: each entry declares the files, what the recipe expects to exist, and how to adapt the sample data to yours. "Set this up against my real accounts" is a one-line prompt.
