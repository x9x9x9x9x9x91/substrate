Everything here is a plain markdown file on disk. A note becomes a database row by gaining properties — nothing ever moves.

## The basics

- **⌘K** — command palette: open anything, create anything, search everything
- **⌘N** — capture a thought into the Inbox, zero filing decisions
- **⌘1 / ⌘2 / ⌘3** — Inbox, All notes, Recent
- Link notes with [[Slow Bloom EP]] style wikilinks — backlinks appear at the bottom of each note
- Property chips under a note's title are its frontmatter — the same note is a row in every view that matches

## Checklists and tables

- [ ] tasks render as real checkboxes — click one to flip it
- [x] done items dim out
